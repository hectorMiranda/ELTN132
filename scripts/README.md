# Scripts

This directory contains utility scripts and tools for the ELTN 132 course.

## Contents

- `example_circuit_analysis.py` - Example Python script for circuit analysis
- Additional scripts will be added as the course progresses

## Usage

### Python Scripts

1. Ensure Python 3.x is installed
2. Install required dependencies (if any):
   ```bash
   pip install -r requirements.txt
   ```
3. Run scripts:
   ```bash
   python script_name.py
   ```

### MATLAB Scripts

1. Open MATLAB
2. Navigate to the scripts directory
3. Run the script by typing its name (without .m extension) in the command window

## Dependencies

- Python 3.7 or higher
- NumPy (for numerical computations)
- Matplotlib (for plotting)
- SciPy (for signal processing)

Install Python dependencies:
```bash
pip install numpy matplotlib scipy
```
