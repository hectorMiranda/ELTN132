# Resources

This directory contains reference materials and resources for ELTN 132.

## Contents

### Reference Materials
- Circuit analysis formulas
- Component datasheets
- Design guidelines
- Standard values for resistors, capacitors, etc.

### Software Tools
- Circuit simulation software guides (SPICE, Multisim, etc.)
- Programming resources (Python, MATLAB)
- Measurement equipment documentation

### Learning Resources
- Tutorial links
- Video lecture references
- Additional reading materials
- Online calculators and tools

## Recommended Tools

### Circuit Simulation
- LTspice (free SPICE simulator)
- ngspice (open-source SPICE)
- Falstad Circuit Simulator (online)

### Programming
- Python 3.x with NumPy, SciPy, Matplotlib
- MATLAB/Octave
- Jupyter Notebook

### Documentation
- LaTeX for technical reports
- Markdown for quick documentation
- Draw.io for circuit diagrams
