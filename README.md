# ELTN132 - Digital and Control Electronics

**Course:** ELTN 132 #80031  
**Semester:** Fall 2025  
**Topic:** Digital and Control Electronics

## Overview

This repository contains course materials, scripts, lab exercises, and homework assignments for ELTN 132. The course covers fundamental concepts in digital electronics and control systems, including circuit analysis, signal processing, and control theory.

## Quick Start

### Prerequisites
- Python 3.7 or higher
- Git
- (Optional) MATLAB or GNU Octave
- (Optional) Circuit simulation software (LTspice, ngspice, etc.)

### Installation

1. Clone this repository:
```bash
git clone https://github.com/hectorMiranda/ELTN132.git
cd ELTN132
```

2. Install Python dependencies:
```bash
pip install numpy matplotlib scipy
```

3. Run the example script:
```bash
cd scripts
python example_circuit_analysis.py
```

For detailed setup instructions, see [docs/GETTING_STARTED.md](docs/GETTING_STARTED.md).

## Using This Repository

### Scripts
The `scripts/` directory contains Python and MATLAB scripts for circuit analysis, signal processing, and other computational tasks. Each script includes documentation and usage examples.

**Example:**
```bash
cd scripts
python example_circuit_analysis.py
```

### Labs
Laboratory exercises are organized in the `labs/` directory. Each lab includes objectives, procedures, and data analysis templates.

### Homework
Homework assignments are in the `homework/` directory. Follow the submission guidelines in each assignment folder.

### Resources
The `resources/` directory contains reference materials, datasheets, formulas, and links to useful tools and tutorials.
