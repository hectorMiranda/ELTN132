# Laboratory Exercises

This directory contains lab exercises and experiments for ELTN 132.

## Lab Structure

Each lab should include:
- Lab instructions/objectives
- Required materials
- Procedure/steps
- Data collection templates
- Analysis scripts
- Report templates

## Lab Guidelines

1. **Safety First**: Always follow proper safety procedures when working with electronic circuits
2. **Documentation**: Keep detailed notes of your observations and measurements
3. **Analysis**: Use the provided scripts to analyze your experimental data
4. **Reports**: Submit lab reports according to the provided templates

## Upcoming Labs

Labs will be added throughout the semester covering topics such as:
- Digital logic circuits
- Analog-to-Digital conversion
- Control systems
- Signal processing
- Circuit simulation and analysis

## Submission

Follow the course guidelines for lab report submission.
