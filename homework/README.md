# Homework Assignments

This directory contains homework assignments for ELTN 132.

## Structure

Each homework assignment is organized in its own subdirectory:
- `hw1/`, `hw2/`, etc.

Each assignment directory should contain:
- Problem statements
- Solution templates
- Required data files
- Submission guidelines

## Submission Guidelines

1. Complete all problems as specified
2. Show all work and calculations
3. Include code comments for programming assignments
4. Test your scripts before submission
5. Follow the naming convention: `lastname_firstname_hwX`

## Grading Criteria

- Correctness of solutions
- Code quality and documentation
- Clarity of explanations
- Timeliness of submission

## Academic Integrity

All work submitted must be your own. Collaboration is encouraged for learning, but submitted work must be individually completed.
